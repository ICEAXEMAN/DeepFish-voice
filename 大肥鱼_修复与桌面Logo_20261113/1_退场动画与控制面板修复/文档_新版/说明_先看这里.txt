- 以前在收起（退场动画正在播）的时候点面板右上角的叉，托盘图标随后会跟着消失，看着就像整个桌宠退了，
  而且再也没有入口把控制台叫回来。
- 现在：叉 / Esc 只把面板收起来，面板不退出、也不会打断她的退场动画；她收着的时候托盘图标一直留着，

- 托盘判断“她是不是走了”也放宽了：要连续几次问不到、离开最后一次应答 6 秒以上才算，
  收起/出场那几秒里接口慢一下不会被误判成退场。

【怎么跑】
  1. 把模型放进 model\（上面那条）。
  2. 双击「启动桌宠.bat」，或者运行 bin\FishPet.exe。第一次启动会慢几秒（编译着色器），正常。
  3. 桌面图标：跑过 setup.ps1 之后，桌面上会有「大肥鱼桌宠」快捷方式（图标是 assets\大肥鱼.ico）。
     双击它 = 她收着就叫她出来 / 没在跑就启动她 / 托盘小图标丢了也顺手补回来。
     没生成、或者被删了：运行 创建桌面快捷方式.ps1（加 -NoDesktopShortcut 可以让 setup.ps1 别建）。
  4. 想让她用网页接口/接 AI：照 AGENTS.md 第 6 步接 bin\FishPet.Mcp.exe。
  5. 想用实时语音（现编的话也能念）：双击「启动语音服务.bat」（本机 GPT-SoVITS，127.0.0.1:9880）。

【语音（这套的重点）】
- voice\            青春、活力。467 条固定台词 + 新做的欢迎 5 条（W-01…W-05），48 kHz、0.95 倍速。
- voice_calm\       冷静、沉稳。同上 472 条，称呼「ボス」。
- 切换：托盘控制台 → 语音 →「固定台词语音包」（青春、活力 / 冷静、沉稳），立刻生效、下次打开也记得。
- 欢迎台词：welcome.txt（青春）和 welcome_calm.txt（冷静），按当前语音包自动选一份；
  气泡里的中文和 index.json 里的键一一对应，改了台词就要重做对应的 W-0x.wav。
- 只说一次：第一次出场说完，settings.json 里记 Welcomed=true；以后不再说。

【文件都是干什么的】
- bin\              桌宠程序和 MCP 接口（已编译）
- renderer\          Live2D 渲染器：源码在 renderer\*.cpp，编译好的在 renderer\build\Release\
- tray\             托盘控制台源码，编译好的在 tray\app\
- src\              桌宠本体的 C# 源码（含 Welcome.cs / PetWindow.Welcome.cs）
- audio\            听电脑里的音乐（跟着跳）用的采集脚本
- hooks\            干活时的反应：Claude Code 的 hook、DeepSeek Harness 的插件包
- prompt\           给角色看的身体说明和可选规矩（装到 AI 人设里）
- docs\功能详解.md  完整功能介绍；docs\语音功能交接.md  语音这套是怎么做的、怎么加新台词
- 台词：alarms / mutter / skits / touch / touch_calm / events / stroke / hover / dizzy / welcome / welcome_calm
- README.md（公版首页）、AGENTS.md（给 Agent 的安装手册）、CLAUDE.md（Claude Code 入口）、LICENSE / NOTICE / COMMERCIAL.md
