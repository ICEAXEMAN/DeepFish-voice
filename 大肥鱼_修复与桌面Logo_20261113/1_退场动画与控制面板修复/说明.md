# 修复：退场动画 + 关闭控制面板（2026-11-13）

改的是桌宠本体（FishPet）和托盘控制台（FishTray）。已编译、部署到正在运行的那份桌宠里。

## 现象（老大报的）

- 点「收起」后，大肥鱼正在播退场动画（面板上显示「收起中…」）时，点控制台面板右上角的 ✕：
  面板没了，托盘小图标也跟着没了 —— 看起来像整个桌宠都退出了，而且再也找不到入口把控制台叫回来。
- 想要的是：关掉控制台面板（不是点「退出控制台」）不应该让桌宠一起退出。

## 原因

1. 面板右上角的 ✕ 本身只调用 `Hide()` 把窗口藏起来，并不会退出程序。
2. **但托盘图标的规则是「她在场 或 面板开着才显示」**：她一旦收好，图标就藏起来；
   面板再一关，屏幕上没有任何入口 —— 看起来等于退出了。
3. 控制台每秒问一次桌宠「你还在吗」，**原来只要 2 秒问不到就自己退出并关掉面板**。
   收起/出场那几秒里接口稍微慢一下，就会被误判成她走了，控制台（和面板）随即消失。
4. 另外：Alt+F4 / 系统关闭会把面板窗口真正销毁（WPF 之后不允许再 `Show()`），面板就再也打不开了。

## 行为对照

| 操作 | 以前 | 现在 |
|---|---|---|
| 她在桌面上点 ✕ / Esc | 面板收起（图标还在） | 一样，面板收起 |
| 她收起时点 ✕ | 面板和托盘图标都消失，像退出 | 面板收起；托盘图标留着，点一下能再打开面板 |
| 收起动画中接口慢一下 | 控制台 2 秒后自己退出 | 最多等十几秒，而且收起/出场 15 秒内不判退场 |
| Alt+F4 / 系统关闭面板 | 窗口被销毁，再也打不开 | 只收起，能再打开 |
| 她真的跟着 Agent 退场 | 控制台 2 秒后跟着退 | 十几秒后跟着退（设计没变，只是不再误判） |
| 点右键「退出控制台」 | 只退出控制台，不动桌宠 | 一样（这是原来的行为） |

## 验证（当天实测）

- 用 UI 自动化照老大的操作走了一遍：点收起（出现「收起中…」）→ 趁动画点 ✕ → 面板收起；
  4 秒后 `hidden=true`（她收好待命），12 秒后桌宠、控制台进程都还在；再打开面板显示「收起着」，点出场就回来。
- 还测了 Alt+F4/WM_CLOSE：面板只收起，能再次打开（改动前会抛出「无法设置可见性」）。
- 逻辑测试 `FishPet.Tests`：1355 项通过。
- 托盘日志里能看到 `托盘图标出现（hidden=True，面板关着）`，证明她收起时图标还在。

## 部署与重新编译

- 线上程序：`bin\FishPet.exe/.dll`、`tray\app\FishTray.exe/.dll`（本目录 `程序_已部署\` 是同一版副本）。
- 旧程序备份：`大肥鱼桌宠_完整包\大肥鱼桌宠\bak\20261113-面板关闭修复\`。
- 重新编译（在插件文件夹里跑，第一次几分钟）：
  ```
  powershell -ExecutionPolicy Bypass -File setup.ps1 -Check
  ```
  只重编这两个项目也可以：
  ```
  dotnet publish src\FishPet\FishPet.csproj -c Release -o bin
  dotnet publish tray\FishTray\FishTray.csproj -c Release -o tray\app
  ```
