# 桌面 Logo 与快捷方式（2026-11-13）

桌面上那个「大肥鱼桌宠」快捷方式，以及它用的图标，都在这里留一份。

## 这个文件夹里有什么

| 文件 | 说明 |
|---|---|
| `原始Logo_1024.png` | 老大给的原始图（白底方形，1024×1024） |
| `大肥鱼.png` | 处理好的透明背景 PNG（1024×1024，和图标同一张图） |
| `大肥鱼.ico` | 快捷方式用的图标：16/20/24/32/40/48/64/96/128/256 共 10 档 |
| `大肥鱼-预览.png` | 256×256 的预览图（就是聊天里发的那张） |
| `快捷方式启动.vbs` | 快捷方式实际运行的启动器（放在插件文件夹里） |
| `大肥鱼桌宠.lnk` | 桌面快捷方式的副本（里面写的是本机插件路径，换台电脑不能直接用，按下面的命令重建） |
| `做图标.py` | 重新生成图标的脚本（Python + Pillow） |

## 图标是怎么做的

1. 把原始图四角的**白底**沿着边挖成透明（贴纸里面的白圈被深蓝描边包着，不会误挖）。
2. 按 16→256 十个尺寸各存一帧，装进 `大肥鱼.ico`。
3. 桌面上的图标读的就是插件里的 `assets\大肥鱼.ico`。

想换图重做（在插件文件夹里跑，Python 需要装 Pillow）：

```
python 做图标.py 原始Logo_1024.png 大肥鱼.png 大肥鱼.ico
```

## 快捷方式

属性（`大肥鱼桌宠.lnk`）：

| 项 | 值 |
|---|---|
| 目标 | `C:\Windows\System32\wscript.exe` |
| 参数 | `"<插件文件夹>\快捷方式启动.vbs"` |
| 起始位置 | `<插件文件夹>` |
| 图标 | `<插件文件夹>\assets\大肥鱼.ico` |
| 备注 | 大肥鱼桌宠：点一下叫她出来 |

双击以后（`快捷方式启动.vbs` 里做的事，全程不弹窗口）：

1. 读插件里的 `api.json`，问本机接口她是不是在跑：
   - **在跑** → `POST /call/show`：收着就叫她出来（带问候），已经在桌面上就把她提到最前。
   - **没在跑** → 启动 `bin\FishPet.exe`（它会自己把托盘控制台也带起来）。
2. 如果 `FishTray.exe`（托盘控制台）不在 → 顺手把它启动回来，小图标就回来了。

## 重建这个快捷方式

最快：在插件文件夹里运行（`setup.ps1` 每次也会自动跑一遍；`-NoDesktopShortcut` 可以不建）：

```
powershell -ExecutionPolicy Bypass -File 创建桌面快捷方式.ps1
```

下面这条手动命令（和脚本做的事一样）留着备用，路径按实际插件文件夹替换：

```powershell
$live  = 'C:\Users\14623\Desktop\大肥鱼桌宠_完整包\大肥鱼桌宠'
$lnk   = Join-Path ([Environment]::GetFolderPath('Desktop')) '大肥鱼桌宠.lnk'
$sh    = New-Object -ComObject WScript.Shell
$s     = $sh.CreateShortcut($lnk)
$s.TargetPath       = Join-Path $env:SystemRoot 'System32\wscript.exe'
$s.Arguments        = '"' + (Join-Path $live '快捷方式启动.vbs') + '"'
$s.WorkingDirectory = $live
$s.IconLocation     = Join-Path $live 'assets\大肥鱼.ico'
$s.Description      = '大肥鱼桌宠：点一下叫她出来'
$s.Save()
```

换完图标如果桌面上没变：按 F5，或者在桌面右键「刷新」。

## 注意

- 快捷方式和图标都是按**绝对路径**指过去的：**插件文件夹挪位置或改名**后，快捷方式会失效
  （图标也会变成白纸），把上面的命令重跑一遍即可。
- `快捷方式启动.vbs` 必须留在插件文件夹里；它靠自己的位置（`WScript.ScriptFullName`）找 `bin\`、`tray\` 和 `api.json`。
- 图标文件别删：快捷方式引用的是插件里的 `assets\大肥鱼.ico`。

## 第一次部署（别的用户）会怎样

- `setup.ps1` 跑完会在**用户自己的桌面**生成「大肥鱼桌宠」快捷方式（`[Environment]::GetFolderPath('Desktop')`，
  桌面被 OneDrive 接管也找得对），不需要用户手动建；不想建就加 `-NoDesktopShortcut`。
- 双击它：插件里已经有 `api.json`（她跑过）→ 调本机接口叫她出来；还没有 → 直接启动 `bin\FishPet.exe`。
- 桌面快捷方式本身是 `.lnk`，内容就是上面那张表，换台电脑重新生成一次即可。

## 踩过的两个坑（改这几个文件时别再踩）

1. **`.ps1` 必须存成带 UTF-8 BOM**。Windows PowerShell 5.1 读没有 BOM 的 UTF-8 脚本会当成 ANSI（GBK），
   中文全乱、直接语法错——`setup.ps1`、`创建桌面快捷方式.ps1` 都是带 BOM 存的。
2. **`.vbs` 反过来：不能带 BOM**（WSH 会报 `Invalid character`），并且 `MSXML2.XMLHTTP` 没有
   `setTimeouts`（错误 438）；错误码会一直留到最后，把明明成功的 `/call/show` 判成失败。
   现在的写法是每步 `Err.Clear` 再判断，改动 `快捷方式启动.vbs` 时别把这几行删了。
